# Project: LeaseLens

Build a polished Streamlit application that allows users to enter a rental address and receive a property risk report based on rental listings, landlord information, complaints, reviews, and nearby rent prices.

Do not create or configure Apify Actors or Elasticsearch. Create placeholders where the required links, IDs, and credentials can be added later.

## File structure

- `app.py`: Streamlit app entrypoint
- `services.py`: Placeholder service functions for rental data and review aggregation
- `scoring.py`: Score calculation logic
- `demo_data.py`: Sample results for demo mode
- `.env.example`: Environment variable template
- `requirements.txt`: Python dependencies
